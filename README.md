# Game Filter App

A modern, interactive game filtering application built with **React**, **Vite**, **MobX**, and **TypeScript**. Experience a seamless and responsive interface for filtering and exploring games.
<img width="935" alt="Screenshot (32)" src="https://github.com/user-attachments/assets/56be2248-b288-4840-91db-fa5da1862757" />


## 🌟 Features
* **Dynamic Filtering**: Filter games based on multiple criteria with real-time updates
* **Responsive Design**: Fully responsive interface that works across all devices
* **State Management**: Efficient state handling with MobX
* **Type Safety**: Built with TypeScript for enhanced reliability
* **API Integration**: Seamless data fetching with Axios

## 🛠️ Technology Stack
* **Frontend Framework**: React 18
* **Build Tool**: Vite 6
* **State Management**: MobX 6
* **Routing**: React Router DOM 7
* **HTTP Client**: Axios
* **Styling**: Sass
* **TypeScript**: For type safety
* **Testing**: Jest & React Testing Library

## 🚀 Getting Started

1. Clone the repository and install dependencies:
```bash
git clone https://github.com/snishan/game-filter-app-fe.git
cd game-filter-app
npm install
```

2. Checkout to the  `development` brach or change the `.env` file in the root directory:
```env
VITE_API_URL=http://localhost:3001
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173` to view the app.

5. To run tests:
```bash
npm test
```
